`numpy.searchsorted` supports multidimensional arrays
-----------------------------------------------------
`numpy.searchsorted` and ``ndarray.searchsorted`` no longer require the
sorted array to be one-dimensional. Each 1-D slice along the last axis of
``a`` is searched independently. The searched keys are the last axis of ``v``
and any leading axes broadcast against the leading axes of ``a``, so one set
of keys can be searched in every slice. ``sorter`` may now have the same
shape as ``a``. To search along another axis, bring it to the end first, for
instance with `numpy.moveaxis`. This feature is available for all built-in
dtypes except ``StringDType``, which remains one-dimensional.
