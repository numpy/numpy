### Python scalar promotion and casting

- {func}`numpy.concatenate` with `axis=None` and {func}`numpy.choose` now raise
  `OverflowError` for Python integers outside the result dtype's range,
  instead of wrapping.
- Ufuncs, {func}`numpy.copyto`, and {func}`numpy.concatenate` now enforce the same Python
  scalar restrictions for `casting="no"` as for `casting="equiv"`.

See {ref}`arrays.promotion.python-scalar-casting` for the detailed rules.
