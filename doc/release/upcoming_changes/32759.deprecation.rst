``np.dot`` with ``a.ndim >= 2`` and ``b.ndim > 2`` is deprecated
-----------------------------------------------------------------

When the first argument has 2 or more dimensions and the second argument has
more than 2 dimensions, `numpy.dot` and `numpy.ndarray.dot` place the leading
dimensions of the second argument in the middle of the result. This behavior
is confusing and rarely intended, and is now deprecated.
Use ``numpy.tensordot(a, b, axes=[-1, -2])`` for the same result,
or ``numpy.matmul`` / ``@`` for standard batched matrix multiplication.

The C-API functions ``PyArray_MatrixProduct`` and ``PyArray_MatrixProduct2``
emit the same `DeprecationWarning` for these inputs.
