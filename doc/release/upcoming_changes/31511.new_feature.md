### New `descending` keyword argument for {func}`numpy.partition` and {func}`numpy.argpartition`

Users can now pass the `descending=True` keyword argument to {func}`numpy.partition` and
{func}`numpy.argpartition` to partition and argpartition arrays in descending order.
NaN values, if present, are partitioned to the end of the array in both ascending and
descending sorts. This feature is available for all built-in dtypes except
`void` and `generic`.
