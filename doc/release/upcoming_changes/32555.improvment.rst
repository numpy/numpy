Upcasting `bool` in `PyUFunc_DivisionTypeResolver()`
----------------------------------------------------
Previously, dividing `timedelta64` array by boolean raised `_UFuncBinaryResolutionError` because of expected integer or floating point type for the seconds operand. 
The change modifies the type checking where boolean upcasted to int64. Where `True` maps to 1 and `False` masp to 0.

.. code-block:: python

    m = np.array([1], dtype="timedelta64[s]")
    b = np.array([True])

    m/b
    """
    Before: 
    Traceback (most recent call last):
    File "<stdin>", line 1, in <module>
    numpy._core._exceptions._UFuncBinaryResolutionError: ufunc 'divide' cannot use operands with types dtype('<m8[s]') and dtype('bool')

    After:
    array([1], dtype='timedelta64[s]')
    """
