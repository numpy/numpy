### Faster reductions for exact ndarrays

{func}`numpy.sum`, {func}`numpy.prod`, {func}`numpy.min`, {func}`numpy.max`, {func}`numpy.amin`, {func}`numpy.amax`,
{func}`numpy.any`, and {func}`numpy.all` now avoid Python dispatch overhead for exact
{class}`numpy.ndarray` inputs, reducing call times for benchmarked small-array
reductions by approximately 30%-50%. Subclasses and custom array types
continue to use the original `__array_function__` dispatch path.
