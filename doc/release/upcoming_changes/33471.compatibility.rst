``dtype`` argument of ``ndarray.any`` and ``ndarray.all`` has been removed
--------------------------------------------------------------------------
The previously undocumented ``dtype`` argument of ``ndarray.any`` and
``ndarray.all`` has been removed. Use ``np.logical_or.reduce(..., dtype=..., ...)``
or ``np.logical_and.reduce(..., dtype=..., ...)`` instead.

``dtype`` used to be the second positional argument, so the methods now take
their positional arguments in the documented order ``(axis, out, keepdims)``.
For example, ``a.any(axis, out)`` now writes to ``out`` instead of raising a
``TypeError``, which also fixes ``np.matrix.any`` and ``np.matrix.all`` with
``out``.
