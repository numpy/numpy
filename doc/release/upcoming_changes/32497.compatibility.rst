Python scalar promotion and casting
-----------------------------------

- `numpy.append` now follows NEP 50 promotion rules. Appending ``1`` to a
  ``uint8`` array keeps ``uint8``; appending ``300`` raises ``OverflowError``.
- `numpy.concatenate` with ``axis=None`` and `numpy.choose` now raise
  ``OverflowError`` for Python integers outside the result dtype's range,
  instead of wrapping.
- Ufuncs, `numpy.copyto`, and `numpy.concatenate` now enforce the same Python
  scalar restrictions for ``casting="no"`` as for ``casting="equiv"``.

See :ref:`arrays.promotion.python-scalar-casting` for the detailed rules.
