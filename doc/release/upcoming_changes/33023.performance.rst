``numpy.cov`` uses less memory and time for many observations
-------------------------------------------------------------
For an input of a few megabytes or more with at most 128 variables,
`numpy.cov` no longer copies the whole input to a floating point array and
centres that copy. It converts and centres a few hundred kilobytes of columns
at a time, so the extra memory is about a megabyte instead of the size of the
input as ``float64`` (eight times the input for ``uint8`` data), and the call
is about twice as fast. The result can differ from the previous one in the
last few bits. Calls with ``y``, ``fweights`` or ``aweights`` are unchanged.
