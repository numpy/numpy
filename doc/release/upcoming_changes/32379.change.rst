``numpy.generic.astype`` does not copy for immutables when data types are equivalent 
------------------------------------------------------------------------------------
``numpy.generic.astype`` previously used to copy for immutables even when ``copy`` was set to ``False``.
Now, it returns the input for immutables when ``copy`` is ``False`` and ``dtype`` is equivalent
to the data type of the object, or regardless of ``copy`` when the scalar already has exactly
the requested type.
