`numpy.linalg.svd` and `numpy.linalg.lstsq` raise on non-finite input
---------------------------------------------------------------------
`numpy.linalg.svd`, `numpy.linalg.lstsq` and functions built on them such as
`numpy.linalg.pinv` now raise ``LinAlgError`` for input containing ``inf``,
as they already did for ``nan``. Some LAPACK implementations never returned
for such input.
